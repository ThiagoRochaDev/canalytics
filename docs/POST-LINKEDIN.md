# Texto principal

Publiquei a primeira prévia do Canalytics no GitHub: um estúdio de analytics open source para criadores de conteúdo.

A proposta é reunir canais, transmissões e comunidades em uma interface, mantendo o contexto de cada plataforma: histórico, evolução, conteúdos e métricas disponíveis pela API oficial.

A primeira prévia já tem:
• analytics por canal, comparação de períodos e exportação CSV;
• biblioteca de conteúdos e consulta de retenção do YouTube;
• múltiplas contas e áreas de trabalho;
• temas claro, escuro e sistema, com interface para celular;
• instalação própria e código sob Apache-2.0.

YouTube e Twitch têm adaptadores implementados. Discord e TikTok estão em fase experimental; Bilibili está no roadmap.

As imagens e os vídeos desta postagem usam canais fictícios de teste. Os fluxos com contas reais ainda precisam de homologação. Prefiro deixar esse estágio claro desde o começo.

Repositório e documentação: https://github.com/ThiagoRochaDev/canalytics
